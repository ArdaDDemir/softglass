## 3) v1.3 — Atom sprintleri

### 1.3a — Feedback atoms (Must)

| | |
|--|--|
| **Neden** | Spinner var; ilerleme / durum yok |
| **DoD** | Progress + StatusDot (+ isteğe CountBadge veya Badge API notu) · playground · docs · registry · typecheck/build/test |
| **Yapma** | Chart, full dashboard KPI |

**Ship:**
- `Progress` — linear; `value` / indeterminate; size; look softglass
- `StatusDot` — online / busy / offline / custom color
- (opsiyonel aynı sprint) `CircularProgress` — yoksa 1.3d Should

### 1.3b — Form controls (Must)

| | |
|--|--|
| **Neden** | Form kit’te Slider / Number / File eksik |
| **DoD** | Controlled API + field meta (`label`/`hint`/`error`) · klavye · 4 dilde okunur |
| **Yapma** | Range product suite, upload backend, dropzone farm |

**Ship:**
- `Slider` — single value
- `NumberInput` — steppers + min/max/step
- `FileField` — solid surface, label/hint/error, basic file list (no cloud)

### 1.3c — Chrome atoms (Must)

| | |
|--|--|
| **Neden** | Link/Chip/Password/Search olmadan atom “ürün UI” yarım |
| **DoD** | Export + playground + docs + registry |
| **Yapma** | Icon pack, typography kit |

**Ship:**
- `Link` — next-friendly (`href` + optional external)
- `Chip` — selectable + removable (+ optional selected)
- `CloseButton` — shared dismiss (Chip/toast chrome)
- `PasswordInput` **veya** Input extension: reveal toggle (tercih: ince `PasswordInput` atom)
- `SearchInput` — clear + search affordance (free text; Combobox değil)
- `VisuallyHidden` — a11y primitive

### 1.3d — Should atoms (1.3 sonu veya 1.3.x)

- `SegmentedControl`
- `PinInput` / OTP
- `Kbd`, inline `Code`
- `CircularProgress` (a’da yoksa)
- `NavLink` (active)
- `ListItem` (leading/trailing slots)
- `SkipLink`
- `CharacterCount`
- `Fieldset`
- `Icon` wrapper only (no icon set)
- `Image` framed + fallback
- `Meter` (read-only bar)
- `CopyButton`
- `TimeInput` (HH:mm string; no TZ engine)
- `ClientOnly`
- `ScrollArea` (hafif)
- `Rating`
- `AspectRatio`

### 1.3e — Nice (1.3.x veya 1.4’e kaydır)

- `RangeSlider`
- `ColorSwatch` / basit `ColorInput`
- `ToggleGroup` (Segmented yetmezse)
- `FilterChip` / `CheckChip` → mümkünse `Chip` variant
- `CountBadge` → veya Badge API
- `Highlight`, `Truncate`
- `LiveRegion`
- DatePicker extract: `Calendar` / `MonthPicker` / `YearPicker` (refactor only)
- `NativeDateInput` skin
- `Text` / `Heading` (sadece tutarlılık; typography kit iddiası yok)

### 1.3.0 publish checklist

1. Version `1.3.0` (tokens + ui)  
2. CHANGELOG `[1.3.0]`  
3. typecheck + test + build + pack:check  
4. `npm whoami` = ardaddemir; gh = ArdaDDemir  
5. publish tokens → ui  
6. tag `v1.3.0` + push  

**1.3 bilinçli YAPMA:** Icon pack, full Typography system, Box/Stack kit, DataTable, Framer Motion, Theme builder, 4+ dil, Date range suite.
