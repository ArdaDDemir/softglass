### 1.5a — Shell *(Must)*

| | |
|--|--|
| **Neden** | AppShell sadece desktop sticky sidebar; mobil nav yok; collapse yok; sayfa başlığı pattern yok |
| **Branch** | `feat/v1.5a-shell` |
| **Yapma** | Nested app router, multi-level sidebar tree, rail icon library |

**Ship:**

| Piece | Rol | API taslağı |
|-------|-----|-------------|
| `AppShell` | Layout organism | `collapsed` / `defaultCollapsed` / `onCollapsedChange`; `mobileNavOpen` / `defaultMobileNavOpen` / `onMobileNavOpenChange`; `mobileNavTitle`; existing `header` `sidebar` `children` |
| `AppShellMenuButton` | Header hamburger | Context-aware; toggles mobile drawer |
| `AppShellCollapseButton` | Desktop rail toggle | Context-aware; toggles `collapsed` |
| `ShellNavItem` | Nav link | optional `icon`; collapsed = icon (or glyph) + sr-only label |
| `PageHeader` | Page chrome molecule | `title` `description?` `breadcrumbs?` `actions?` `look` `size` |

**Davranış kararları (kilitli):**

1. **Collapse** = desktop only (≥900px). Collapsed width token `--sg-sidebar-width-collapsed` (~4.5rem). Nav labels hide; icons remain.  
2. **Mobile drawer** = reuses **Sheet** (`side="left"`) with the same `sidebar` slot content. Not a second layout implementation.  
3. **Controlled + uncontrolled** both for collapse and mobile open (same pattern as Collapsible).  
4. **PageHeader** = molecule (not organism). Reuses `Breadcrumb` when `breadcrumbs` given. Does not own AppShell.  
5. AppShell becomes **client** (`"use client"`) because Sheet + state.

**Playground (1.5a):**
- Live AppShell mini-frame: collapse toggle + mobile menu button  
- PageHeader: crumbs + title + actions; look strip  

**Test smoke:**
- AppShell: collapse toggle updates `data-collapsed`; menu button opens mobile sheet (role=dialog)  
- PageHeader: title text; breadcrumb count when items passed  

**Tokens:** CSS for collapsed rail + page-header chrome → tokens package touches (bump on 1.5.0 publish).
