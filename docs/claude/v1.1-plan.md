## 5) Sprint detayları

### Sprint A — Overlay ailesi (kit hissi)

**Neden önce?** Softglass’ta menü dili yarım: Select var, ama “…” menü / popover / context yok. Kullanıcı bunu hemen hisseder.

| | |
|--|--|
| **Hedef** | `DropdownMenu`, `Popover` (ve istek olursa `ContextMenu`) — glass look + `look` / `motion` uyumu |
| **DoD (bitti sayılır)** | Export + playground demo + API.md satırları + LIMITATIONS dürüst not + typecheck/build yeşil |
| **A11y min** | Escape kapat, dış tık, klavye (ok/roving veya menü pattern), focus restore |
| **Yapma** | Combobox, DatePicker, full floating-ui her edge case |

**Foundation’a eklenecekler (tahmini):**

```
packages/ui/src/molecules/dropdown-menu.tsx   (veya atoms/ — karar implement öncesi)
packages/ui/src/molecules/popover.tsx
packages/ui/src/molecules/context-menu.tsx    (opsiyonel A.2)
packages/ui/src/index.ts
packages/tokens/src/…                        (menü paneli yüzey / gölge token gerekirse)
apps/web/src/components/…-demo.tsx
docs/API.md, docs/LIMITATIONS.md
registry/registry.json                       (item sketch — CLI C’de)
CHANGELOG.md                                 (sprint sonunda veya 1.1.0’da)
```

**Alt adımlar (A içinde sırayla):**

1. API kararı: isimler, controlled/uncontrolled, portal mi?  
2. Popover iskeleti (en basit floating surface)  
3. DropdownMenu (trigger + items + separator + destructive item)  
4. Playground + docs  
5. (Opsiyonel) ContextMenu  
6. Self-review checklist (aşağı §7)

**Riskler:** Positioning (viewport collision), focus trap vs menu focus, Select ile stil tutarsızlığı → Select yüzey token’larını yeniden kullan.

---

### Sprint B — Motion polish (cila)

**Neden A’dan sonra?** Overlay’ler de exit/enter kullanacak; önce A, sonra ortak exit dili B’de oturur.  
*(İstersen B’yi A’dan önce de yapabilirsin — bağımlılık zayıf; tavsiye yine A→B.)*

| | |
|--|--|
| **Hedef** | Modal/Select (ve yeni overlay) **exit**; Toast **stack** choreography |
| **DoD** | `prefers-reduced-motion` bozulmaz; playground’da enter+exit görünür; todos C2 ilgili maddeler [x] |
| **Opsiyonel** | Card tilt, label-float, directional tabs — sadece DoD sonrası, ayrı mini-PR |

**Foundation’a eklenecekler (tahmini):**

```
packages/tokens/src/motion-recipes.css       (exit / stack reçeteleri)
packages/ui/src/molecules/modal.tsx
packages/ui/src/atoms/select.tsx
packages/ui/src/molecules/toast.tsx
packages/ui/src/molecules/dropdown-menu.tsx  (A’dan geliyorsa exit bağla)
apps/web playground demoları
docs + CHANGELOG
```

**Alt adımlar:**

1. Exit pattern kararı (CSS `data-state` + unmount delay vs anında)  
2. Modal exit  
3. Select / Dropdown exit  
4. Toast stack motion  
5. Reduced-motion doğrulama  
6. Self-review

**Riskler:** Unmount timing bug (animasyon bitmeden DOM silinmesi); a11y’de “hareket zorunlu” olmaması.

---

### Sprint C — Registry install path (vaat)

**Neden kritik?** PUBLIC-MODEL Phase 2: “npm + copy ownership”. v1’de sadece `registry/registry.json` sketch var.

| | |
|--|--|
| **Hedef** | Kullanıcı Softglass registry URL’i ile en az **bir** component’i `shadcn` CLI ile projeye kopyalayabilsin |
| **DoD** | Taze Next app’te documented komut çalışır; tokens + 1–2 UI item kopyalanır; GETTING-STARTED veya ayrı REGISTRY.md |
| **Yapma** | Tüm registry’yi mükemmel index’e submit; tam docs marketing site (E) |

**Foundation’a eklenecekler (tahmini):**

```
registry/registry.json          (tam item listesi, path’ler doğru)
registry/… veya public host     (raw GitHub / Vercel static)
docs/REGISTRY.md veya GETTING-STARTED genişletme
README status checkbox
(opsiyonel) apps/web veya ayrı static host pipeline
```

**Alt adımlar:**

1. shadcn registry schema doğrula (güncel şema)  
2. Item path’lerini consumer-copy için netleştir  
3. Host stratejisi: GitHub raw mı, Vercel mi? (karar kaydı)  
4. 1 smoke: Button + tokens  
5. Docs + README  
6. Self-review

**Riskler:** CLI şema değişimi; monorepo path’lerinin copy hedefiyle uyumsuzluğu; “npm vs copy” kafa karışıklığı → docs’ta iki yol net ayrılmalı.
