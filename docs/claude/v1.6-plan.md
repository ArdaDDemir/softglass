## 5) Teknik model

### 5.1 Routing

| | |
|--|--|
| **Liste** | Gallery page `library` (mevcut) |
| **Detay** | `library` + selected id → hash `#library/button` veya state `selectedId` |
| **Geri** | “← Library” net |

Hash önerisi: `#library` | `#library/<componentId>`  
(`componentId` = `docs.ts` `id`: `button`, `appshell`, …)

### 5.2 Component playground manifest

Her bileşen için (el yazımı, typed):

```ts
// apps/web/src/components/playground/library/manifest.ts
type ControlDef =
  | { kind: "enum"; prop: string; options: string[]; default: string }
  | { kind: "boolean"; prop: string; default: boolean }
  | { kind: "text"; prop: string; default: string }
  | { kind: "node"; prop: string; presets: { label: string; value: "none" | "icon" } };

type ComponentPlayground = {
  id: string;              // matches COMPONENT_DOCS.id
  title: string;
  render: (props: Record<string, unknown>) => ReactNode;
  controls: ControlDef[];
  /** Static strips: all variants / looks without binding live state */
  showcases: { title: string; render: () => ReactNode }[];
};
```

**docs.ts** → prop table + import + summary (zaten var).  
**manifest** → canlı UI. İkisi `id` ile join.

### 5.3 Klasör

```
apps/web/src/components/playground/
  catalog.ts                 # gallery tour (1.5)
  gallery-shell.tsx
  pages.tsx                  # Library → list + detail shell
  library/
    manifest.ts              # registry of playgrounds
    ComponentStudio.tsx      # shared chrome: back, stage, controls, docs
    pages/
      button.tsx
      input.tsx
      card.tsx
      …
```
