## 4) API taslağı (kilitli öneri)

### 4.1 High-level — `DataTable<T>`

Column-driven molecule (Pagination/List diline yakın: controlled + uncontrolled).

```ts
type DataTableLook = "soft" | "solid" | "glass" | "outline" | "ghost";
type DataTableDensity = "comfortable" | "compact";
type DataTableSortDirection = "asc" | "desc";
type DataTableSortState = {
  columnId: string;
  direction: DataTableSortDirection;
} | null;
type DataTableSelectionMode = "none" | "single" | "multiple";

type DataTableColumn<T> = {
  id: string;
  header: ReactNode;
  accessor?: keyof T & string;
  cell?: (row: T, index: number) => ReactNode;
  sortable?: boolean;
  sortValue?: (row: T) => string | number | boolean | null | undefined;
  align?: "start" | "center" | "end";
  width?: string | number;
};

type DataTableProps<T> = {
  data: T[];
  columns: DataTableColumn<T>[];
  getRowId?: (row: T, index: number) => string;
  look?: DataTableLook;           // default "soft"
  density?: DataTableDensity;     // default "comfortable"
  stickyHeader?: boolean;         // default true
  loading?: boolean;
  empty?: ReactNode;              // override; default EmptyState
  emptyTitle?: ReactNode;
  emptyDescription?: ReactNode;
  selectionMode?: DataTableSelectionMode; // default "none"
  selectedIds?: string[];
  defaultSelectedIds?: string[];
  onSelectionChange?: (ids: string[]) => void;
  sort?: DataTableSortState;
  defaultSort?: DataTableSortState;
  onSortChange?: (sort: DataTableSortState) => void;
  /** Client-side sort when sort active. false = server owns order. Default true. */
  clientSort?: boolean;
  "aria-label"?: string;
};
```

## 8) Softglass dil kuralları (tablo)

1. **Look** = surface recipe (`data-look`); enterprise MUI/Ant grid CSS yok  
2. **Density** = row padding (`comfortable` | `compact`) — List ile uyumlu isimler  
3. **Glass** = chrome only; hücre metni solid okunur  
4. **Selection** = mevcut `Checkbox` atomu  
5. **Empty** = mevcut `EmptyState`  
6. **Motion** = reduced-motion güvenli; row hover soft; sort icon subtle  
7. **Sticky header** = thead hücreleri sticky + surface match
